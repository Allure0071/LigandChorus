# E18 正式训练与四模型复现

## 在服务器复现

从仓库根目录运行以下命令。使用项目已有的 Python 3.11.15 和 PyTorch 2.5.1+cu121 环境。正式计时配置固定为服务器的物理 GPU 0（RTX 4090 D）。这些命令需要访问 [assets.json](assets.json) 中的目录。训练、校准和跑批均使用新的输出路径。

```bash
PY=/data/yxhuang/anaconda3/envs/ligandmpnn/bin/python
REPLAY=reproduction/2026-11-27/reproduce.py
WORK=$(mktemp -d)

"$PY" -B "$REPLAY" verify --server
"$PY" -B "$REPLAY" rescore
"$PY" -B "$REPLAY" prepare-inputs --output "$WORK/prepared_inputs"

"$PY" -B "$REPLAY" infer --output "$WORK/e18_samples.npy"
"$PY" -B "$REPLAY" train --output "$WORK/training"
"$PY" -B "$REPLAY" calibrate --output "$WORK/calibration"
"$PY" -B "$REPLAY" benchmark --output "$WORK/benchmark"
```

`verify` 也可在本地运行，省略 `--server` 即可。`rescore` 使用服务器保存的标准化预测重算全部评分，并逐值对照仓库内的正式报告。`prepare-inputs` 从冻结的候选清单重建 PDB、NPZ 和目标残基映射，核对其哈希并再次运行四个解析器。`infer` 默认读取一个已有开发结构，使用 `--input` 可传入符合项目结构格式的 NPZ。

训练入口支持 `--smoke`，用 2 个训练组装体跑 1 步，并在记录的验证集上完成验证和保存。校准入口的 `--smoke` 使用两个验证结构。四模型的 `benchmark --smoke` 仅跑两个开发结构，每模型每结构 10 条。完整跑批先验证开发样本，再对锁定的测试清单执行四个模型的常驻推理。现有基准采用归档的 `best.pt` 和校准设置。新重训或新校准的权重与参数应记录为一次新的实验。

共享测试清单含 **80 个酶结构（8 个家族）**和 **60 个通用非酶结构（7 个家族）**。四模型读取相同的骨架和指定配体，按同一套目标残基编号评分。测试口袋使用相距指定配体重原子小于 5 Å 的天然侧链重原子位点。候选清单、正式输入、评分参考均可按 [assets.json](assets.json) 的哈希核对。两个基准分组的完整评分记录包含逐结构和按家族汇总。

## 推理设置

| 模型 | 正式设置 |
| --- | --- |
| E18 | `best.pt`。距上下文原子小于 5 Å 的 Cα 位点使用温度 0.12，其余用 0.29，最多 20 个采样步骤。温度在项目的 128 个验证结构上，以原版 LigandMPNN 0.10 的整链和口袋多样性为参照选出。 |
| 原版 LigandMPNN | `ligandmpnn_v_32_010_25.pt`，温度 0.10，每批 10 条，启用配体上下文。 |
| LASErMPNN | `laser_weights_0p1A_noise_ligandmpnn_split.pt`，全局和第一壳层温度均为 0.10，每批 2 条，允许半胱氨酸。3 个配体启用上游的非标准氨基酸配体选项。结构输出对照官方理想化骨架核验。 |
| ADFLIP | `ADFLIP_v1.pt`，自适应采样最多 8 步，置信阈值 0.9，最后一步取 argmax。逐条运行，并按官方流程执行侧链重建。 |

每模型每结构生成 10 条序列，共 5,600 条。结构种子为 20261127 加正式清单行号（从 0 开始）。ADFLIP 每条序列的种子为结构种子乘 100，再加该结构内的序列序号（从 0 开始）。配置锁定了模型权重、批大小和关键脚本的哈希。

## 正式结果

以下均为各组的结构级中位数。恢复率取每结构 10 条序列的天然残基匹配率。多样性取同一结构内 45 对序列的平均位点差异率。推理耗时在同一张 RTX 4090 D 上预热后记录，单位为秒/结构，每结构生成 10 条序列。权重加载、最终文件写盘、外部评分分开记录。模型推理所需的侧链重建计入推理时间。
