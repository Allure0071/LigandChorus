# 方案一在新版 E18 数据上的正式对照

训练从随机解码器开始，使用 5,044 个酶组装体，仅监督目标链有效掩码位置。五阶段训练沿用方案一，推理保留整个组装体的骨架和指定配体，与归档 E18 一样从整条盲化输入生成，评分只取冻结映射列出的目标残基。两种采样器共享一次 25,000 步训练轨迹。

1. **选权。** 每 1,000 步在固定的 128 个验证结构上用配额采样器、E18 原采样器分别生成 10 条。两者独立选择口袋恢复率中位数最高的检查点，同分保留较早检查点。此阶段固定口袋内外温度 0.29/0.24。
2. **调温。** 对两份最佳权重分别遍历原协议的 6×6 区域温度网格。复用原协议在 128 个结构上的 LigandMPNN 0.10 验证结果，按原排序函数最小化目标链及口袋多样性的最大绝对偏差。保存全部 36 个候选与锁定配置。
3. **测试。** 先锁定两臂配置，再按冻结清单顺序盲评 80 个酶结构和 60 个非酶结构，每结构、每配置采样 10 条。采用作者编号映射、天然侧链重原子定义的 5 Å 口袋及按组的结构中位数。另用原版 E18 的归档权重、温度及采样器重放作为评分路径校验。

从仓库根目录运行以下命令。`OUT` 指向个人工作区下的新目录。训练与测试使用和同学一致的 RTX 4090 D、FP32、PyTorch 2.5.1+cu121。训练脚本仅缓存冻结编码器的 FP32 表示，保存两个按对应采样器选出的完整最佳权重及末步权重。正式指标采用[原评分协议](../2026-11-27/README.md)。

```bash
python -B -u reproduction/plan1_formal/run.py train --out "$OUT"
python -B -u reproduction/plan1_formal/run.py calibrate --out "$OUT"
python -B -u reproduction/plan1_formal/run.py score --out "$OUT"
```
