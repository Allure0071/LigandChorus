# 常规结构预训练 → 酶序列适配

本实验使用两份独立初始化的解码头、两套独立优化器，在相同结构抽样顺序下比较方案一（五阶段掩码）与 E18（连续掩码）。两者共享冻结的官方 LigandMPNN 结构编码表示。源坐标分片只读，第一阶段清单记录原路径、行号或分片索引。

| | 常规预训练 | 酶适配 |
|---|---:|---:|
| 组装体数 | 50,000 | 5,044 |
| 每个模型独立优化步数 | 100,000 | 25,000 |
| 每步独立组装体数 | 4 | 4 |
| 监督位置 | 所有具有天然标签的有效掩码位置 | 指定目标酶链的有效掩码位置 |
| 选权与调温 | 使用末步权重直接进入下一阶段 | 每 1,000 步按 128 个验证簇的口袋恢复率中位数选权，之后独立校准区域温度 |

第一阶段预期平均抽到每个组装体 8 次；第二阶段约 19.8 次。随机均匀抽样下，实际次数随记录而变。两阶段沿用 AdamW、学习率 0.0001、权重衰减 0.01、梯度裁剪 1.0 和 FP32。切换阶段时继承权重、优化器动量和随机数状态。每 1,000 步原子保存可续训检查点，阶段一末步额外保存两份权重及完整交接检查点。

运行前先确认拆分审计中已冻结 50,000 个组装体及清单哈希。`SPLIT` 为实验私有清单目录；`OUT` 为新输出目录。服务器实验启动脚本另外固定 GPU 和个人环境。

```bash
python -B -u reproduction/two_stage/train.py --split "$SPLIT" --out "$OUT"
python -B -u reproduction/plan1_formal/run.py calibrate --out "$OUT"
python -B -u reproduction/plan1_formal/run.py score --out "$OUT"
```

正式训练中断后使用 `--resume` 从最近的提交边界继续。正式测试仍使用酶组 80 个结构、通用组 60 个结构；所有校准参数和两个最佳检查点固定后才调用评分入口。输出中的 `quota` 对应经过两阶段训练的方案一，`legacy` 对应经过两阶段训练的 E18。配对比较对照分别是此前只用酶数据训练的方案一配额版本和同学新版 E18。
